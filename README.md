##  v1.1.4 Agent 功能亮点

###  Agent 管理与安全

- **Agent Dashboard**: 全新 Web UI 管理界面 (/agents),可视化管理所有 agent 配置、工作空间和文件

- **GitHub Copilot**: 支持最新 gpt-4.1 模型
- **Windows 优化**: 指数退避重试解决文件锁定冲突
- **会话恢复**: 向导支持 Gateway 重启后自动恢复
